# vehicles_app
A repository for sprint4 final task

Descrição do Projeto: 
**Aplicativo Web de Venda de Veículos**
Este aplicativo web interativo foi desenvolvido em Python utilizando o Streamlit, Pandas e Plotly. O objetivo principal da aplicação é fornecer uma interface visual, simples e dinâmica para a exploração e análise de dados de um mercado de veículos (*baseado no conjunto de dados vehicles_us.csv*).

A ferramenta permite que qualquer usuário interaja com os dados em tempo real, facilitando a identificação de padrões e tendências de mercado sem a necessidade de escrever código.

**Funcionalidades Oferecidas**
Visualização de Histograma da Quilometragem (odometer):

Um botão de seleção (checkbox) que, quando ativado, gera e exibe um histograma interativo mostrando a distribuição da quilometragem dos veículos cadastrados na base de dados.

Gráfico de Dispersão (Scatter Plot) - Preço vs. Quilometragem:

Um segundo botão de seleção (checkbox) que permite ao usuário visualizar a relação direta entre a quilometragem (odometer) e o preço (price) dos veículos, ajudando a analisar como o uso afeta a desvalorização do carro.
